8 · Recomendaciones

🔴 Alta — Activar PWA / Service Worker
El arranque del frontend muestra PWA support is disabled. Para activar el modo offline y cumplir con RES-012, PER-007 y PER-008, revisar la configuración de next-pwa en next.config.ts.
🔴 Alta — Headers de Seguridad HTTP
Verificar que Nginx o la capa de producción sirve Content-Security-Policy, X-Frame-Options, Strict-Transport-Security y X-Content-Type-Options.
🔴 Alta — Caché de Firestore para APIs de Datos
Los endpoints /api/lugares, /api/tours y /api/paquetes superan ligeramente 2 000 ms. Implementar caché en memoria (Redis o in-process) para estas colecciones estáticas reduciría la latencia sustancialmente.
🟡 Media — Ruta /api/ia-place en Frontend
La ruta proxy de Next.js hacia el servidor IA no responde. Verificar la configuración del proxy en next.config.ts.
🟡 Media — Pre-warming de Rutas Next.js en Dev
Los cold starts afectan /login, /, /forgot-password, /informacion/[nombre], /admin/negocios y /admin/lugares. En producción no ocurre, pero en dev se puede mitigar aumentando el timeout del script o pre-calentando las rutas.
🟡 Media — Rate Limiting en Login
El límite configurado es 20 intentos/15 min. El requerimiento AUT-013 especifica máximo 3. Considerar reducir loginLimiter de 20 a 5 para cumplir más cercanamente con el requerimiento de seguridad.
🟢 Baja — Servidor pitzbol-web IA
Levantar el servidor en :3003 para ejecutar las pruebas del motor IA (S7) y validar IA-001 a IA-018.
🟢 Baja — Pruebas de Integración de Email
Los requerimientos BOO-012 y GUI-P07 (emails de confirmación y notificación) no son verificables automáticamente. Considerar integración con Mailtrap u otro sandbox de email.
