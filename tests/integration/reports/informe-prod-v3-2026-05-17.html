API pendiente: HTTP 525 en todos los endpoints
  • Causa: Cloudflare SSL "Full" intenta conectar a api.pitzbol.me en puerto 443, donde OpenVPN intercepta la conexión.
  • Fix requerido: Cloudflare → Rules → Origin Rules → redirigir api.pitzbol.me e ia.pitzbol.me al puerto 8443 (nginx + Let's Encrypt).
  • Restaurar symlink nginx: sudo ln -sf /etc/nginx/sites-available/pitzbol-api /etc/nginx/sites-enabled/pitzbol-api && sudo nginx -t && sudo systemctl reload nginx
